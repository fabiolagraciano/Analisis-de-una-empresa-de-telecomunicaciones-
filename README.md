# Analisis-de-una-empresa-de-telecomunicaciones-
Proyecto de sprint 7 

Objetivo: evaluar el comportamiento de los clientes de ConnectaTel, mediante tres datasets "plans", "users", y "usage" durante el año 2024 

Análisis: se realizó una inspección y detección de problemas de calidad de los datos, seguido de una limpieza, posteriormente se realizó un análisis descriptivo con medidas estadísticas, para poder generar visualizaciones de outliers, al finalizar se realizó una segmentación por grupos de edad y grupos de uso.
